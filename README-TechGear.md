# TechGear

A responsive e-commerce frontend for a modern tech gadget store, built with **HTML, CSS, and JavaScript**.

TechGear demonstrates a complete frontend shopping experience, including product discovery, search, cart management, account flows, checkout, and order confirmation.

## Live Demo

[View TechGear Live](https://irtiza-dev.github.io/techgear/)

## Features

- Responsive modern e-commerce interface
- Product browsing and search
- Individual product pages
- Shopping cart with quantity controls
- Cart persistence using LocalStorage
- Login and account interface
- Checkout flow
- Order confirmation page
- Contact page
- Responsive layout for desktop, tablet, and mobile

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage
- GitHub Pages
